# Future identity briefs

No new identity is adopted for this preservation release. The inherited pixel-X
icon stays in place. These briefs are saved for a separately decided relaunch;
they don't imply that the archived upstream project is active again.

## Minimal

Create a restrained toolbar icon for 4chan XT, a browser tool for filtering and
following imageboard discussions. Use two interlocking thread paths with clear
negative space and a muted green accent. Avoid the 4chan clover and avoid a generic
security shield. No text. It must read at 16 pixels and on light and dark surfaces.
Output a 1024 by 1024 PNG in RGBA with alpha 0 outside the glyph. No checkerboard,
solid background, glow or watermark. Use simple geometry suitable for later vector work.

## App icon

Design an app icon for 4chan XT, a tool for organizing imageboard discussions.
Use an open square frame with two ordered discussion markers, not speech-bubble
clip art. Keep green as a restrained accent. No text or clover. Use high contrast
on light and dark surfaces and simple geometry that remains clear at 48 pixels.
Output a true transparent 1024 by 1024 RGBA PNG, alpha 0 outside the actual icon.
No checkerboard, full-canvas background, glow or watermark.

## Wordmark

Set the exact words "4chan XT" in a restrained custom sans-serif wordmark for a
browser discussion organizer. Use an optical correction between the numeral and
lowercase letters; make XT clear without oversizing it. No slogan, clover or shield.
Use clean opaque letterforms with high contrast on light and dark surfaces.
Output a 2048 by 640 RGBA PNG with alpha 0 everywhere outside the letters. No glow,
checkerboard, solid or textured background, watermark or additional text.

## Emblem

Create a compact emblem for 4chan XT, an imageboard discussion tool. An open angular
frame encloses an orderly pair of thread paths. It should suggest following a
conversation, not site ownership, anonymity or security certification. No words,
clover or heraldic shield. Keep the construction simple, distinctive at small size
and readable on light and dark surfaces. Output a 1024 by 1024 RGBA PNG with real
alpha 0 outside the emblem. No checkerboard, background fill, glow or watermark.

## Abstract

Explore an abstract mark for 4chan XT, a browser tool that helps readers filter and
follow discussions. Show one selected path among several offset lines without
drawing a literal chat bubble. Use limited green and graphite shapes with optical
balance, generous negative space and strong light/dark contrast. No text, clover
or shield. Output a true transparent 1024 by 1024 RGBA PNG. Everything outside the
mark must have alpha 0; no checkerboard, background fill, glow or watermark.

For every result, inspect the alpha channel and compare at actual toolbar sizes.
Reject a baked-in transparency preview or a mark that depends on a large mockup.
Save all originals and document the selection before replacing an existing asset.
